rodar os comandos;

- npm install.
- node server.js.

instalar a extensão do VsCode "Five Server" (gratuita);

- após instalada, pelo VsCode mesmo, clicar com o
  botão direito no arquivo "frontend_atividade.html".
  
- selecionar a opção "Open with Live Server".
  
- isso abrirá uma aba em seu navegador padrão que
  terá o Card de Register para completar.
